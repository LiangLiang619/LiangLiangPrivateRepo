## 概述
- 活动时间：预热 6.30 起，正式 7.4—8.29，共 8～9 周；分 chiikawa / 柯南 / 斗罗大陆三个 IP 阶段轮换上新（策划案《元梦广场·系统规则》）。
- 我的角色：主要负责。"大王别抓我"符箓投掷物系统由他人支援完成，**不计入我的产出**。

## 功能模块与技术点

### 模块 1：宣传区 — 主楼大屏 / 宣传栏海报轮播 + 跳转（可复用系统）
- **功能描述**：主楼大屏与宣传栏读取策划配置的海报；仅 1 张时静态展示，>1 张时按配置顺序每 X 秒轮播；靠近时弹交互按钮，点击跳转到对应运营活动；支持大屏/宣传栏分别配空、按秒配置显示时间。
- **我的实现**：抽出一套可复用的"旋转展示屏"基类，快闪季屏做子类接入（简历强调"可复用的主楼大屏与宣传栏"）。
- **技术点**：
  - `[表现/工程复用]` 轮播展示做成通用基类 + 活动子类：`BP_IA_UMGRotatingDisplayComponentBase.lua`（基类）+ `BP_IA_UMGSummerDisplayScreenComponent.lua`（快闪季子类），配置表 `ResRotatingScreenData`。`⚠️[待核实]`
  - `[网络同步]` 轮播为纯客户端表现，但按**服务器时间**对齐，保证所有玩家看到同一张海报（时间驱动而非各端本地计时）。`⚠️[待核实]`
  - `[状态管理]` 海报"显示时间/下架时间/跳转 id 可配空"的分支：配空则不显示交互按钮/仅指定屏展示。
- **代码位置**：`Content/LetsGo/Script/Modplay/Interactive/Component/`。`⚠️[待核实]`
