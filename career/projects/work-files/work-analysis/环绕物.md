## 工作内容拆解（GP 侧）
- **装备/卸载 + Avatar 数据流解析**：玩家装备/卸载环绕物后，通过角色 Avatar 数据流下发到各端；我在 `UpdateSurroundingsInfo` 里遍历 `AvatarInfos` 数组，识别 `ItemType_Surroundings(212)`，读商品配置的 `surroundingsEffectId`，做"新装备 / 换装 / 卸载"三种情况的差异处理。
- **常驻环绕物表现**：按特效配置生成粒子/网格，挂到角色骨骼或跟随 Actor 上；第一次进游戏延迟 0.8s 显示（等角色实体生成完），支持一个环绕物挂多个特效（多个普通 + 至多一个可跟随）。
- **idleShow 演出接入**：角色进入 idleShow 状态时，按"首次必播、之后按概率"播放 idleShow 特效并同步播放音效；主控端开关同步给 DS 再广播给其他模拟端；处理与常驻特效、时装自带环绕物的互斥。
- **平滑跟随**：可跟随特效绑到 C++ `UCharacterVFXFollower` 驱动的 Actor 上，按"距离→速度"映射实现自然平滑跟随，支持速度对齐拖尾朝向。
- **二期性能重构**：常驻环绕由 particle 迁移为 **mesh + 曲线（`UAnimTransformData`）驱动轨迹**，idleShow 改为动画表现，拖尾附着到 mesh；核心运动逻辑由 Lua 下沉到 C++。
- **多玩法性能保底**：接入 `PerfWeightModel`，按场景 + 距离限制"1+X"个环绕物显示（主角必显），配置化的 Action/Motion State 黑名单在特定状态隐藏环绕物。
- **载具/道具适配**：乘坐载具时切到载具专用挂点；变大/变小道具同步缩放；隐身道具时隐藏环绕物。
- **资源分包**：环绕物量产后接入 `CharacterAvatarChunkInScene` 按需下载，未下载不显示、下载完立即显示，本人/他人差异化下载优先级。

### [3C-角色 / 状态机] idleShow 子状态：C++ 状态机 + Lua 覆写回调（首次必播 / 之后按概率）
- C++ `UMoeCharActionStateIdleShow::OnEnter` 里，先走环绕物分支：`GetSurroundingsIdleShowSwitch()` → `IsHitSurroundingsProbability()` → `EnterSurroundingsIdleShow()` 三个 `BlueprintNativeEvent` 依次通过才 `bIsEnterSurroundings=true` 并 `return`（跳过角色普通 idleShow）；否则走普通 idleShow（Montage/Sequence 异步加载）。C++ 默认实现是兜底（switch=false、概率=RandBool、Enter=true）。`[一手：MoeCharActionStateIdleShow.cpp:37-50/677-696]`
- `OnUpdate` 退出条件：`bIsEnterSurroundings` 时，超时（`SurroundingsIdleShowTime`）或角色开始移动（`LocomotionAnimState != Moe_OnGroundMove` 或速度非零）就 `ExitSurroundingsIdleShow` 并退状态；`OnExit` 也会兜底 `ExitSurroundingsIdleShow`。`[一手:563-660]`
- Lua 侧 `BP_SurroundingsComponent` 覆写：`GetSurroundingsIdleShowSwitch` 读 `BagModel:GetItemStatusByItemId`（玩家手动关演出则返回 false）；`IsHitSurroundingsProbability` 用 `SurroundingsIdleShowCallCount`，**首次取 `FirstProbability`（默认 100，必播），之后取 `NonFirstProbability`（默认 50）**，`math.random(0,1000) % 100 + 1 < Probability` 命中。`[一手]`
- `FilterNormalAndIdleShowEffect`：按配置 `type`（1/3=idleShow，0/2=普通）把一个环绕物的多个特效拆进 `idleShowEffectId` / `normalEffectId` 两组。`[一手]`
- idleShow 播放时同步播 `soundId` 音效（`MOE_3C.SoundMgr:ReceivePlaySfx`）。`[一手]`
- **代码**：`BP_SurroundingsComponent.lua:SurroundingsIdleShow:253 / GetSurroundingsIdleShowSwitch:1029 / IsHitSurroundingsProbability:1048 / GetIdleShowProbability:1072 / FilterNormalAndIdleShowEffect:932`；C++ `MoeCharActionStateIdleShow.cpp:OnEnter:33 / OnUpdate:563 / OnExit:596`。`[一手]`

### [C++ / 性能表现] 平滑跟随组件 `UCharacterVFXFollower`：双阈值门控 + 距离→速度映射 + 速度对齐拖尾
- `USceneComponent`，`PrimaryComponentTick.TickGroup = TG_PrePhysics`（在物理前更新，避免与角色移动打架）。`[一手：CharacterVFXFollower.cpp]`
- 每帧：取角色骨骼 socket 位置为目标点，**双阈值门控** `bShouldUpdatePosition = (CharacterSpeed >= VelocityThreshold) || (DistSquared > PositionUpdateThreshold²)` —— 速度够大或距离拉开才更新，静止时不抖。`[一手]`
- 速度映射：`CurrentSpeed = MapRangeClamped(Distance, 0, MaxDistance, Speed, MaxSpeed)`，`MoveDistance = min(DeltaTime*CurrentSpeed, Distance)`，实现"离得越远追得越快、贴身缓行"的自然跟随；对应配置里的 `speed / maxSpeed / maxDistance`。`[一手]`
- `bVelocityAligned`：按运动方向算 `Rotation`，`Roll=0` 去侧倾、`Yaw -= rotationOffset` 让拖尾朝向对齐速度。`[一手]`
- 曲线叠加：若挂了 `LocalTransformData`，每帧 `Eval(worldTime)` 得到本地位移，叠加到跟随位置（`NewParticlePosition + LocalTranslation`），实现"绕圈轨迹 + 整体跟随"的合成运动。`[一手]`
- Lua 侧参数注入：`Helper_SetFollowerParameter` 把配置的 `speed/maxSpeed/maxDistance` 写进组件（缺省回退 500/1500/1000）；`VelocityThreshold/PositionUpdateThreshold` 从 `SurroundingsParamData` 配表覆盖。`[一手]`
- **代码**：`Plugins/MOE/EnginePlugins/EnvironmentSystem/ParticleVAT/Source/ParticleVAT/Private/CharacterVFXFollower.cpp:TickComponent`、`BP_SurroundingsComponent.lua:Helper_SetFollowerParameter:711 / SpawnFollower:312`。`[一手]`

## 难点与解决方案
- **静止抖动 / 跟随不自然**：单纯每帧插值会在静止时抖、追赶时突兀 → 双阈值门控（速度或距离触发）+ `MapRangeClamped` 距离→速度映射，静止不更新、拉开距离加速追。`[一手]`（对应验收表 #19"跟随速度三参数不生效"的修复）
- **常驻 particle 性能开销大**：二期把常驻环绕改为 **mesh + 曲线离线烘焙 + 运行时 Lerp/Slerp 采样**，把每帧粒子模拟换成一次数组插值，并把运动逻辑从 Lua 下沉 C++。`[一手]`
- **首次必播 vs 之后按概率**：idleShow 用 `SurroundingsIdleShowCallCount` 区分首次/非首次概率，既保证第一次一定看到演出，又控制后续频率。`[一手]`
- **载具骨骼绑定错乱**：`bIsOnVehicle` 分支 + `posOnVehicle` 专用挂点字段，解决绑 Bip001 绑到载具的问题。`[一手：对应验收 #1/#5/#11]`
- **变身/隐身/换装/断线的状态一致性**：buff 监听 + `cachedAvatarInfo/cachedCharacter` 缓存 + 幂等换装判断 + EndPlay 清理（含修过的 `OnAddBuffDelegate` 空指针 CrashSight），保证多情况下环绕物不残留、不重复。`[一手：git log + 代码]`
- **切场景/切关卡残留与延迟**：第一次进游戏延迟 0.8s 显示等角色生成；验收 #23"切关卡环绕物飞 20 秒才回到身边"→ 每关开始前销毁、开始后重建（⚠️ 该条派给 @innerchen，我这边是否参与待确认）。
