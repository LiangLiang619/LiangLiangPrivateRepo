## 概述
- **一句话定位**：给大厅"互动道具"新增一类**可 DIY 的手持玩具（痛包）**——玩家把用【吧唧】拼好的 2D 痛包拿在手上循环展示，DIY 结果与展示动作**同步给全场其他玩家可见**；我负责这个商品从"装备→进入手持状态→播放展示动作→3C 轮盘操作→状态数据多端同步→有效期/引导/换装等边界处理→农场等副玩法接入"的整条 GP 链路。
- **商品形态**：互动道具大类 →【玩具】类 → 与【推图展板】平行的子类。层级在代码里**一手确认**：角色手持玩具状态基类 `MoeCharActionStateCommonInteractiveToy` 注释"UGC 地图展板/痛包等的基类，需继承该类并实现接口"，痛包子类 `MoeCharActionStateCommonItaBag` 继承它。`[一手]`
- **业务背景**：配合 YM 暑期"痛包快闪"，做游戏内首个支持痛包 DIY 的商品，初期活跃向投放（紫品）、非消耗、支持有效期（限期/永久）。（策划 @牟宇恒；GP 技术预研由我产出，见下）
- **需求/预研文档**：iWiki `4014965087`（**我的 GP 技术预研**，含装备显示/数据同步/技能按钮+3C 面板/操作引导四块拆分与技术方案；文末我还向 @chrisguo 抛了"痛包是否常显"的问题）。

## 工作内容拆解（GP 侧）
- **手持痛包状态机**：把"手持展示痛包"实现为角色 `ActionCommon` 下的一个通用子动作状态，抽象出可复用基类（痛包 / UGC 推图展板共用），子类只填插槽、蓝图、贴图与动画。
- **状态数据多端同步**：把 DIY 结果（贴图 URL）、展示动作序号、字幕等打进 StateData 随状态同步，保证其他玩家看到我手上"这一版"痛包与"正在做的展示动作"。
- **展示动作与表现**：进入即播痛包 idleshow（双手混合到上半身），一次性动作播完自动切循环 idle；换装/Avatar 刷新后自动重挂重播；退出时清理动画与 attach 的痛包 Actor。
- **商品 3C 面板/技能按钮**：装备后出互动道具技能按钮，点击拉起 3C 动作面板（展示动作切换 / 前往装饰界面 / 取消收起），大厅与农场走不同面板窗口。
- **有效期与边界防护**：进入前查过期（过期销毁不进状态）；引导中/隐身 buff 中禁用并 toast；DS 端跳过表现；仅本地角色写"当前展示痛包 id"。
- **副玩法接入**：大厅 / UGC 大厅 / 星家园复用同一套；农场/疯狂农场抽出独立痛包技能按钮与开关接口；农场做农活/收礼时自动退出痛包状态。
- **操作引导**：首次装备痛包触发通用新手引导（事件驱动，修过引导事件发送时机的 bug）。

## 技术点（GP 方向，均落到代码）

### [3C-角色 / UE 框架] 手持痛包做成"通用交互玩具子动作状态"，痛包/推图展板共用基类
- 基类 `MoeCharActionStateCommonInteractiveToy`（注释即写"UGC 地图展板/痛包等的基类，需继承并实现接口"），痛包子类 `MoeCharActionStateCommonItaBag` 只重写 `SetConfig`（`socketName="hand_r"`、`displayAssetName="BP_ItaBag"`）、`DisplayBoard`、`SetDisplayTexture`。`[一手]`
- 状态注册：`MoeCharActionStateCommon.lua` 把 `ECommonActionName.ItaBag → MoeCharActionStateCommonItaBag`；进入统一走 `Character:TryEnterActionState(ECharActionState.ActionCommon, StateData)`。`[一手]`
- 生命周期在 `ReceiveOnEnter_Lua / ReceiveOnExit_Lua`：进入置 `CanPickProp/CanUseProp/CanShowProp=false`、spawn 痛包并 `K2_AttachToComponent` 到 `hand_r`、取 ToyComponent；退出销毁 Actor、停 Montage、复位双手混合、反注册回调。`[一手]`
- **代码**：`Content/LetsGo/Script/Modplay/Character/State/CommonSubAction/MoeCharActionStateCommonInteractiveToy.lua`、`.../MoeCharActionStateCommonItaBag.lua`、`.../MoeCharActionStateCommon.lua`。`[一手]`

### [网络 / 状态管理] 状态数据同步：DIY 贴图 + 展示动作序号随 Action State 同步给全场
- 需求即"吧唧位置/旋转/缩放等自定义数据随展示痛包对应的 Action State 储存进行状态数据同步"（iWiki 我的预研）；实现上把结果化为 StateData 字段同步。`[一手]`
- 基类实现 `SetSyncStateData` / `ParseSyncStateData`：用 `AddOrSetSyncDataInt32/FString` 写、`GetSyncDataInt32/FString` 读，同步 `InteractiveActorConfigID`、`Image`（DIY 结果贴图 URL）、`ConfigIndex`（当前展示动作）、`FloatingSubtitles`（字幕），走 `StateDataProxy.SyncDataFactory`。`[一手]`
- StateData 蓝图 `BP_StateData_DIYItem`，进入时 `SyncActor / Image / InteractiveActorConfigID / ConfigIndex` 一次性灌入并随状态广播；他端解析 `Image` 后异步拉贴图上手持痛包，从而"他人可见我的 DIY 结果"。`[一手]`
- **代码**：`MoeCharActionStateCommonInteractiveToy.lua:SetSyncStateData:141 / ParseSyncStateData:121`；`CharacterActionStateUtil.lua:EnterActionStateCommonInteractiveToy:212`（构造 `BP_StateData_DIYItem`）。`[一手]`

### [网络 / 数据流] DIY 结果贴图：COS/CDN 异步下载上动态材质，含健壮性回退
- `InteractiveToyUtil:GetInteractiveToyTextureUrl`：痛包取 `RootAttrModel:GetBadgeCosUrl(ItemId)`（吧唧拼出的痛包图，`image-2.ymzx.qq.com/itabag/...astc`）；推图展板取 UGC 封面 CDN。`[一手]`
- `BP_InteractiveToyComponentBase:SetToyTextureUrl`：DS 端跳过；客户端经 `DownloadImgModel:GetCDNImageWithUrl` 异步下载，回调前判 `bHasEndPlay` 防悬空，失败 `ResetToyTexture` 回退默认 RT；`InitDynamicMaterial` 建动态材质、`SetMaterialParameter("RT",...)` 上图。`[一手]`
- 线上 bug 佐证（同链路）：`痛包未装备吧唧显示是黑的`、`A 看 B 已装备吧唧的痛包某些角度黑` —— 正是他端 DIY 贴图链路（我做了显示逻辑与防护）。`[一手：git]`

## 难点与解决方案
- **一套状态吃两种玩具**：痛包（DIY 2D 贴片）与推图展板（滚动字幕 + UGC 封面）表现差异大 → 基类沉淀通用生命周期 + 同步 + 动画，子类只填插槽/蓝图/贴图，`actionType` 分派两条流程，配置表驱动。`[一手]`
- **他人视角一致性**：DIY 结果与展示动作必须多端一致 → 用 Action State 的 SyncData（`Image/ConfigIndex/...`）作为权威快照随状态同步，他端解析后异步拉图；异步回调用 `bHasEndPlay` 守卫、无图回退默认 RT，避免"黑痛包"（对应线上 bug 修复）。`[一手]`
- **状态互斥与打断**：播其他 Montage / 做农活 / 打开特定界面时必须干净退出痛包 → `OnMontageStarted` 主动 `TryLeaveActionState`，副玩法侧统一 `TryLeaveActionStateCommonInteractiveToy`。`[一手]`
- **换装丢失**：换装触发 Avatar 重建会丢挂点动画 → 监听 `OnAvatarRefresh` 自动重挂重播。`[一手]`
- **大厅 vs 农场**：3C 面板窗口不同 → `bIsFarm` 分支切窗口 + 农场独立技能按钮开关接口（预研阶段就规划）。`[一手]`

## 量化结果 / 亮点
