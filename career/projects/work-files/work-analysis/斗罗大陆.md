## 一、项目背景与目的

配合斗罗大陆 IP 授权联动，在游戏广场中央区域（"星斗大森林"）推出主题互动玩法。策划目标：
- **商业化曝光**：通过唐三/小舞 NPC 表演持续展示同期卡池皮肤（海神唐三、貂蝉小舞 + 手持物）
- **社交互动**：武魂觉醒（NPC触发 + 玩家互助）、柔骨魅兔魂兽捕捉、蓝银草技能、蓝银草领域
- **IP 融入**：斗罗世界观台词、专属 IPToast UI、等级称号体系（魂师→绝世斗罗 9 阶）

## 四、技术亮点深析

### 4.1 武魂觉醒互动系统

**两条路径：NPC触发 + 玩家互助**

```
NPC 路径：
  玩家对话 NPC
  → DialogueTriggerManager:lAwaken(Dialogue, NpcId, Trigger)
  → DouLuoGPModel:EnterSoulAwakenState(Character, nil, true, npcId)
  → Client2DSRPC("DSEnterSoulAwakenState", {0, isMain, npcId})
  → DS 权威：双人社交动作状态机，BroadcastRPC 通知双方播放觉醒动画

玩家互助路径：
  已觉醒玩家点击"帮助觉醒"按钮
  → DouLuoGPModel:TryDouLuoWaken(Character, otherChar)
  → CharInteractComponent:MoveToInvitee(otherChar, wakenActionId=721062, 300)
  → 双人社交动作框架：发送/接受/拒绝/超时
  → 接受后：EnterSoulAwakenState → DSEnterSoulAwakenState RPC
```

**觉醒演出细节**：
- 双方浮空（升空1s，最高点悬停2s）+ 身周竹笋形动效
- 助力者：紫色尖锐竹笋 + 蓝银草虚影；觉醒者：黄色平缓竹笋 + 蓝银草实体
- 觉醒成功后：`SphereBomb` Actor 生成，`BombComponent` 对周围玩家触发围观（星星眼）+ 冲击波（哭泣倒地）
- 升级动效：`PlaySoulLevelParticle` 在 ActionState 子状态上播放 `LevelUp/LevelUp2` 粒子；到达 99 级再 1s 后播放 `InMaxLevel/LoopMaxLevel/OutMaxLevel` 三段式特效

### 4.2 蓝银草技能决策树（优先级链）

`DouLuoGPModel:UseSilverGrassResult` 按优先级顺序依次判断：

```
1. CanEnterSoulException(Character) → 魂力异常（捆绑搞笑动画）
2. CanCatchRabbit(Character)         → 矩形碰撞检测（宽150, 长1000, 高200）命中 SoulBeast Tag
3. CanMove(Character)                → Pawn 碰撞检测，命中玩家则触发位移
4. 兜底 → 普通蓝银草动作
```

**魂力异常概率与保底系统**（配置表驱动）：

| 阶段 | 称号 | 等级 | 概率 | 保底(连续未中N-1次第N次必中) | 反向保底 |
|------|------|------|------|--------------------------|---------|
| 1 | 魂师 | 11级 | 40% | 3 | 2 |
| ... | ... | ... | ... | ... | ... |
| 8 | 魂斗罗 | 88级 | 5% | 7 | 2 |
| 9 | 绝世斗罗 | 99级 | 0% | — | 2 |

- 连续计数存入 `LuaBBValue`（`SoulExceptionContinuousTriggerCount` / `SoulExceptionContinuousMissCount`）
- DS同步后重置保底计数

**蓝银草位移**：复用大王玩法无忧符箓的位移逻辑（`CharRPCComponent` 客户端预表现）

### 4.3 引导系统（DouLuoGuides）

**5 种引导场景**：

| 序号 | 触发条件 | 指向 | 每日限次 |
|------|---------|------|---------|
| 1 | 持续在广场游玩（首次10s，之后300s loop） | 觉醒按钮 | 3次/天 |
| 2 | 觉醒后等待N秒（可配置） | 觉醒按钮 + 蓝银草按钮 | 1次/天 |
| 3 | 连续5次升级均只捕兽 | 觉醒按钮 | 1次/天 |
| 4 | 连续5次升级均只助力觉醒 | 蓝银草按钮 | 1次/天 |
| 5 | 晋位绝世斗罗后等待N秒仍未使用领域 | 蓝银草领域按钮 | 1次/天 |

**CCD 持久化存储格式**（E_CCD_Key.DouLuoPalyerGuides）：
```
{timestamp1},{count1};{timestamp2},{count2};{timestamp3},{count3};{timestamp4},{count4};{timestamp5},{count5}
```
- `IsSameDay()` 对比当前服务器时间与记录时间戳判断是否同一天
- 每次触发检查并更新 count，达到限次后该引导静默

**Timer 管理**：
- `awakenFirstTimer`（10s 一次性）+ `awakenLoopTimer`（300s 循环）双定时器
- 场景切换时 `CleanUp` 清理所有 Timer（修复了 bug 中跨场景泄漏问题）

### 4.4 NPC 行为组件（BP_CommunityNPCDouLuoComponent）

**双层表演调度**：
```
第一层（普通待机表演）：
  ScheduleNextNormalShow → Timer(30s) → PlayNormalShowAnim
  → 检测手持物开关(FOT_DouLuoHandhold)
  → 播放待机手持物表演动画

第二层（玩家接近触发）：
  chatBoxTrigger.OnComponentBeginOverlap → 检测范围(7广场单位)
  → NPC 朝向最近进入的玩家
  → PlayHandholdShow（CD=15s）
  → 同步触发气泡文本（权重配置表随机）
  ← 与普通待机表演互斥
```

**喊话气泡保证**：唐三和小舞喊话互斥排他，保证广场任意时刻至少一个NPC在喊话（持续时间与CD设置一致）

**特殊对话区域（RunToNPCAndTalk）**：
- BP 碰撞体大小由策划在 UE 编辑器中直接调整
- 玩家进入区域 → 显示特殊UI按钮（与普通对话互斥）
- 点击后调用 `MoveToCharacter` 自动跑向 NPC，距离 2 广场单位处停止
- 自动触发普通对话
- 打断条件：移动/飞扑/跳跃/抱起/其他玩家互动/场景切换

### 4.5 蓝银草领域（Area Skill）

**使用流程**：
```
本地玩家（99级） → UseSilverGrassAreaSkill
→ Client2DSRPC("AddBlueSilverGrassAreaBuff", {buff_name, duration=16.0})
→ DS 生成 Area Actor + 施加 FreezonBuff 到周围玩家
→ 本地 UI：SkillButton SetCircleCD(15)
```

**Freeze 效果**：
- 参照雪人炸弹 freeze 状态，被影响玩家无视重力悬浮在当前动作帧上
- 可通过飞扑/重置按钮逃离（使用 `TeleportToLobbyPosition` 移至距领域中心5000单位的最远出生点）
- 逃离后获得 15s 免打扰 buff
- 领域跟随施放者移动（期间施放者移速减半）
- 施放者本身对自己的领域免疫

**主动中止**：
```
ExitSilverGrassAreaSkill
→ 播放停止动画（TryPlayStopAnim）
→ 标记 area.isInterrupt = true
→ Client2DSRPC("RemoveBlueSilverGrassAreaBuff")
→ 玩家重置回 11 级（觉醒但无领域能力）
```

### 4.6 魂兽（柔骨魅兔）AI

**配表驱动的随机决策**：
```
每次动作后等待 n 秒（权重表：1s=5%, 2s=10%, 3s=40%, 4s=25%, 5s=20%）
→ 在互动区圆内随机选目标点
→ 随机动作（地面小跑70% / 低空跳跃20% / 大跳10%）+ 随机距离（0-5单位）
→ 执行移动
```

**刷新逻辑**：5个配置刷新点，被捕后在距抓捕点最远的刷新点再刷新1只，保持场景内始终有5只魂兽。

### 4.7 性能优化（bug=146586229）

- 斗罗功能开关判断（`GetIfDouLuoSwitchOn`）从每帧查询改为 `OnInit` 时缓存，避免热路径下的系统判断开销
- 删除热路径中的 `print` 日志（Lua gc 优化）
- `GetIfInDouLuoTime` 带 10 帧缓存（`bIsInDouluoTime` + `cacheFrameCount`），避免每帧查服务器时间
